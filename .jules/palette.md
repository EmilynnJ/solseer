# Palette's Journal - UX & Accessibility Learnings

## 2025-05-18 - Icon-Only Controls Pattern
**Learning:** Icon-only controls in React/Vite web applications require combining `aria-label` for screen reader accessibility with matching `title` attributes to provide native hover tooltips for desktop mouse users.
**Action:** Always pair matching `aria-label` and `title` attributes on icon-only buttons across components.
