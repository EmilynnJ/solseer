# Palette's Journal - Critical Learnings

This journal records critical UX and accessibility learnings, patterns, or constraints discovered in this app.

## 2026-09-11 - Initializing Palette's Journal
**Learning:** SoulSeer uses React, Lucide icons, and Tailwind/standard CSS styling across `apps/client`. Vitest tests run via `npm run test -w @soulseer/client` or `pnpm test`.
**Action:** Focus on localized, accessible micro-UX improvements in client UI components without introducing custom CSS classes or backend changes.
