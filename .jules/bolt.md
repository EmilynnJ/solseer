## 2026-09-01 - Prevent Memory Bloat in Drizzle Pagination with Correlated Subqueries
**Learning:** Using `LEFT JOIN` and `GROUP BY` to count related records (e.g., counting comments for posts, or reviews for readers) causes significant memory bloat and performance degradation during pagination due to the database returning a row for every joined record before grouping them.
**Action:** Replace the `LEFT JOIN` + `GROUP BY` pattern with a correlated subquery using `sql<number>'(select count(*)::int from child_table where parentId = ${parent_table.id})'` to significantly improve query performance and reduce memory usage in Drizzle ORM/PostgreSQL.
## 2024-10-02 - React 18+ Image Optimization Support
**Learning:** React 18+ natively supports standard HTML attributes `fetchPriority`, `loading`, and `decoding` directly on `<img>` elements without needing custom types, extra dependencies, or special camelCasing (except for standard JSX formatting like `fetchPriority`). Using `fetchPriority="high"` on hero images and `loading="lazy"` on below-the-fold images, combined with `decoding="async"`, provides significant LCP (Largest Contentful Paint) and main-thread performance boosts natively.
**Action:** Always leverage native `fetchPriority="high"` for above-the-fold hero images and `loading="lazy"` for off-screen images in React applications to improve LCP. Add `decoding="async"` alongside them to prevent image decoding from blocking the main thread.
