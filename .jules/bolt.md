## 2026-09-01 - Prevent Memory Bloat in Drizzle Pagination with Correlated Subqueries
**Learning:** Using `LEFT JOIN` and `GROUP BY` to count related records (e.g., counting comments for posts, or reviews for readers) causes significant memory bloat and performance degradation during pagination due to the database returning a row for every joined record before grouping them.
**Action:** Replace the `LEFT JOIN` + `GROUP BY` pattern with a correlated subquery using `sql<number>'(select count(*)::int from child_table where parentId = ${parent_table.id})'` to significantly improve query performance and reduce memory usage in Drizzle ORM/PostgreSQL.
## 2026-09-09 - Defer Loading Below-the-Fold Images
**Learning:** Native `loading="lazy"` attribute is highly effective for deferring the loading of images that appear off-screen (below the fold) until the user scrolls near them. However, it should never be added to above-the-fold images (like hero banners) as this delays the browser preload scanner and significantly worsens Largest Contentful Paint (LCP).
**Action:** Always verify if an image typically renders off-screen in the viewport before adding `loading="lazy"` to it. For large lists or grid views (like the `ReaderCard` component in lists), native lazy loading is almost always a measurable performance win.
