## 2026-09-01 - Prevent Memory Bloat in Drizzle Pagination with Correlated Subqueries
**Learning:** Using `LEFT JOIN` and `GROUP BY` to count related records (e.g., counting comments for posts, or reviews for readers) causes significant memory bloat and performance degradation during pagination due to the database returning a row for every joined record before grouping them.
**Action:** Replace the `LEFT JOIN` + `GROUP BY` pattern with a correlated subquery using `sql<number>'(select count(*)::int from child_table where parentId = ${parent_table.id})'` to significantly improve query performance and reduce memory usage in Drizzle ORM/PostgreSQL.## 2026-09-17 - Prevent LCP Regression from Lazy Loading
**Learning:** Native image lazy loading is a great optimization but can negatively impact Largest Contentful Paint (LCP) if applied indiscriminately to all images, especially those appearing above the fold on initial render.
**Action:** Always conditionally apply `loading="lazy"` only for images that fall below the fold, while using `loading="eager"` (or relying on browser default) for priority images such as the top elements of lists or hero sections.
