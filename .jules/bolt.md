## 2026-08-31 - Database Optimization: Replace LEFT JOIN + GROUP BY with Correlated Subqueries
**Learning:** In Drizzle ORM/PostgreSQL, doing a `.leftJoin()` on a has-many relation combined with `.groupBy()` for computing aggregates (like count and average rating of reviews) causes significant memory bloat, poor query execution plans, and complicates pagination because the database multiplies the primary rows by the joined rows before grouping.
**Action:** Replace `LEFT JOIN` and `GROUP BY` with correlated subqueries using `sql(...)` for aggregate counts/averages to fetch results cleanly and quickly without expanding the result set in memory. Example: `sql<number>\`(select count(${reviews.id}) from ${reviews} where ${reviews.readerId} = ${readerProfiles.userId})::int\``.
