## 2024-08-28 - Optimizing Pagination and Aggregation with Correlated Subqueries
**Learning:** In Drizzle ORM/PostgreSQL, using `LEFT JOIN` combined with `GROUP BY` to retrieve associated records' counts and averages (like `reviewCount` or `commentCount`) causes massive performance bottlenecks when querying large datasets and during pagination (e.g., combining `LIMIT`/`OFFSET`), because the database must first join and group the entire relation before slicing it. This also balloons memory overhead on reading the result sets.
**Action:** Always replace `LEFT JOIN` + `GROUP BY` patterns for counting/averaging related records with correlated subqueries using `sql\(\`...\`\)` when possible, which execute much faster alongside `LIMIT`/`OFFSET` queries and prevent result set bloat.
