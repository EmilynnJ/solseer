## 2026-08-14 - Decoupled Modal Focus & Keyboard Dismissal Pattern
**Learning:** Standard Modal components in multi-step or dynamic flows (such as community composers and payment forms in this app) are prone to focus-stealing bugs. If focus-on-mount logic is bundled with other hook states or reactive triggers, the browser will repeatedly steal and reset user focus to the modal container on every parent component re-render. Decoupling the focus management into a dedicated, isolated effect with an empty dependency array (`[]`) ensures focus is set exactly once upon modal instantiation without disrupting subsequent active nested inputs.
**Action:** Always separate the initial accessibility focus-on-mount logic from stateful dismissals (like Escape key keydown handlers) in reusable dialog components by placing them in distinct React `useEffect` hooks.
